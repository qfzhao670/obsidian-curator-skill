# 计算机体系结构

计算机只理解二进制的 0 和 1，用比特（bit）表示——比特是计算中最小的数据单位，取值 0 或 1。一个字节（byte）由 8 个比特组成，可表示单个字符（如 `a`）或单个数字（如 `1`）。更大的单位依次为 KB、MB、GB、TB。

## 存储层次

从慢到快、从大到小，存储组件依次为磁盘、内存、缓存。

### 磁盘存储

- **类型**：==HDD 或 SSD==
- **特性**：非易失性——断电或重启后数据仍保留；存放操作系统、应用程序与所有用户文件
- **容量**：几百 GB 到多个 TB
- **速度**：SSD 读取约 500–3500 MB/s，HDD 约 80–160 MB/s；SSD 更贵但明显更快

### RAM（随机存取存储器）

- 紧随磁盘之后的直接访问点，保存当前正在使用或处理的数据结构、变量、应用数据
- 程序运行时，其变量、中间结果、运行时栈等都存于此（读写访问快）
- **特性**：==易失性==——需要供电保持内容，重启后数据可能不持久
- **容量**：消费设备几 GB 到高端服务器数百 GB
- **速度**：读写通常 >5000 MB/s，快于最快的 SSD

### 缓存（Cache）

- 比 RAM 更小（以 MB 计）、访问更快（==L1 缓存仅需几纳秒==）
- 查找顺序：CPU 先查 L1 → 再查 L2、L3 → 最后查 RAM
- 目的：减少访问数据的平均时间，把高频数据放这里以优化 CPU 性能

## CPU

- 计算机的「大脑」，负责取指、解码、执行指令；运行代码时由 CPU 执行程序中定义的操作
- 高级语言（Java、C++、Python 等）需先经 ==编译器== 编译成机器码，CPU 才能执行
- 可从 [[RAM]]、磁盘、缓存读写数据

## 主板

- 连接所有组件，提供组件间数据流动的路径

> [!note] 小结
> 从快到慢：缓存 > RAM > 磁盘；缓存最小最快，磁盘最大最慢且非易失。CPU 按 L1 → L2 → L3 → RAM 逐级查找，以平均访问时间换取性能。
