# 功能①：整理、重排并美化已有笔记

当用户要求整理 / 美化 / 重排一篇或多篇**已有的 markdown 笔记**时，遵循本文件。
Obsidian 特性的具体语法与用法规则见 `references/formatting-guide.md`；成品示例见 `references/example-curated-note.md`。

## 核心原则（优先级最高）

1. **不编造**：只重组、拆分、润色已有内容，绝不新增原文没有的事实、数据、例子或结论。
2. **层级克制**：正文只用 `##` / `###` 两级（极少数 `####`）；`#` 仅当笔记缺标题时补一个标题。不要多级嵌套、不要为了切分而切分。
3. **长段落 → 短段落 + 无序列表**：把并列的要点、步骤、属性拆成 `- ` 列表，一句话讲一件事。
4. **图片原样保留**：`![[...]]` 不动，就近放在相关段落旁，可补一行简短说明。
5. **高亮克制**：保留原文 `==高亮==`，用于关键术语；可适度补，但不泛滥。
6. **排版克制**：表格仅在「对比 / 多列数据」时用；callout 每篇最多 1–2 个；不添加表情、不滥用加粗/斜体。

## 工作流程

1. 读入目标（单篇笔记，或目录下多篇）。
2. 通读，提取主题结构：在讲什么、有哪些并列概念、段落之间什么关系。
3. 重排结构：定标题层级、把并列点拆成列表、相关段落归组。
4. 逐项应用 Obsidian 特性（语法与用法规则见 `references/formatting-guide.md`）。
5. 写回（默认就地编辑原文件；用户要求时输出新文件或只给 diff）。
